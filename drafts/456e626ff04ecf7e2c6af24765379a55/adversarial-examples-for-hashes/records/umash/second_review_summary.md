# Second independent review of the UMASH proof (run by the author, 2026-09-18) — condensed
- Same principal gap: the fibre-count inference (reference line ~1180: ceil(2^64/p)^2 · 2^-63 = 81·2^-63 < 2^-56) does not follow from AU/AXU. Cleaner counterexample: keys (i,j) uniform in {0..60}^2, H(0)=(2^i,2^j), H(1)=(2^i+p,2^j+p): 61^2 distinct XOR differences (1/61^2-AXU) yet R(H(0))=R(H(1)) for every key. Points to VHASH Security's modular-reduction lemma, which assumes almost-Δ-universality for the additive operation.
- Key generator samples the 34 OH words without replacement: exact short-input probabilities 1/(q−1) (not 2^-64), joint 1/((q−1)(q−3)) or 0 (shared index); repair by conditioning on distinctness, factor 1/(1−561/q). Multiplier set {2..p−1}: denominator p−2, prose says p−1.
- NEW: the literate reference's UmashKey has ONE poly field and umash(key, seed, buf, secondary) uses key.poly for both outputs, so the natural fingerprint (primary, secondary) with one key object shares the multiplier. Exact counterexample: f = p−1 gives f^2 ≡ 1, so the double-pumped update is additive and block order does not matter; X = A‖B vs Y = B‖A (full blocks, same tags) collide in both outputs for every OH key and seed; probability ≥ 1/(p−2) ≈ 2^-61 for that pair vs claimed 2^-83. Reproduced with A = 256 zero bytes, B = 256 bytes of 1. Production umash.c has poly[2][2] (two multipliers), so the C fingerprint is the analysed construction; the reference should expose a two-multiplier fingerprint key.
- Event decomposition Pr[fp collision] ≤ β + (α0+α1) r + r^2 (same as our review §2.3); numerical slack is adequate IF post-reduction α ≤ 81·2^-63, β ≤ 81^2·2^-99 (0.816·2^-55 at 4 KiB; 0.600·2^-83 at 64 MiB).
- Unequal lengths: polynomial has no leading marker; (y1,y2) vs (0,0,y1,y2) are the same polynomial; needs point-probability bounds for a compressed block being zero (both compressors jointly).
- Raw algebra confirmed: PH AXU; NH/ENH point mass (2q−1)/q^2; shuffler kernels (max dim 30, 29 for PH) → 2^-99; double-pumped Horner mod 8p reduces correctly; finalizer 1+z^8+z^33 invertible. Repairs: conditional wording p.9 (both raw collisions ≤ 3/q^2); tag-only case harmless for raw equality.
- Smaller: ENH code applies enh ^= (enh % W)*W, i.e. (L,H)→(L,H⊕L), absent from the displayed formula; p.12 mixed estimate uses 2^-25 where 2^-24 follows and 2^-62 instead of ~2^-57; s_{j,n} vs s_{n,j}; "2^29 bits" should be 29 bits; Salsa20 expansion is a pseudorandomness assumption.
