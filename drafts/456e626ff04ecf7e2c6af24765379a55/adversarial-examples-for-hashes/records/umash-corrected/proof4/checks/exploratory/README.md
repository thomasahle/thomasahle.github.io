# Exploratory records

These scripts and snapshots are not proof dependencies. They preserve
candidate-function and prefix relaxations that were considered before the
final proof. The scripts evolved during the investigation; historical
snapshots are not promised to be outputs of the final probe source. None
is an attained all-pairs probability bound or a counterexample.

The original probe imports expected `materials/certify_primary.py`, copied
on the Xeon from the preceding round's `materials/checks3/certify_primary.py`.
The final certificate scripts are self-contained and do not use that import.

`run.log` records an early staged run stopping before the independent reader
file had been transferred. All preceding stages had completed. The reader,
exact envelope stage and manifest were subsequently executed successfully;
see the final `verification.log`, `envelope.log` and JSON certificates in the
parent directory. The published `run_xeon.sh` now has all its source files.
