MurmurHash3_x64_128: a 144-byte every-seed family (four choices per 16-byte block)

In each 16-byte block, h1 ^= g1(k1); h1 = rotl(h1, 27) + h2; h1 = 5·h1 + c; h2 ^= g2(k2); h2 = rotl(h2, 31) + h1; h2 = 5·h2 + c', with g1, g2 public bijections. XOR differences 2^36 (h1 side) and 2^32 (h2 side) rotate onto bit 63, where addition and multiplication by 5 carry an XOR difference exactly. So a block can absorb any incoming top-bit difference (a, b) and emit (r1 ^ b, r2 ^ r1 ^ b) for any choice (r1, r2): four alternatives per block. Eight free blocks and one closing block (r1 = b, r2 = 0) give 4^8 = 2^16 messages of 144 bytes with the same internal state, hence the same 128-bit output for every seed. An 8-byte tail can cancel an h1 difference but not an h2 difference, which gives 2^17 members at 152 bytes.
