Re-analysis of 28 September 2026: programs and logs

Each folder reproduces one new or changed result in the post's changelog. Every program checks the implementation it tests (an SMHasher3 verification value, upstream test vectors or a linked upstream build) before it counts collisions. Upstream sources are pinned by URL and sha256 in each folder's SOURCES.md (and in SOURCES.md for the key-free families). <xeon-host> and <scratch> in logs stand for the compute host and working directory.
